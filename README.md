# React Hooks Project Pack

A collection of eight small React applications built to practice React Hooks through practical, focused projects. Each app should have its own clear purpose, reusable components, and a simple, usable interface.

## Learning Goals

- Understand when to use `useState`, `useEffect`, `useContext`, and `useReducer`.
- Build and reuse custom hooks for shared behavior.
- Manage asynchronous requests and their UI states.
- Keep components focused and easy to test.
- Practice accessible, responsive interfaces with clear feedback.

## Definition of Done

Each project should:

- Run locally without errors.
- Use hooks for the behavior it is intended to demonstrate.
- Include loading, error, and empty states where relevant.
- Work across desktop and mobile layouts.
- Keep secrets such as API keys out of source control.
- Include a short note describing the main hooks and patterns used.
